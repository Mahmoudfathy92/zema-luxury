# ZEMA — Luxury Accessories & Leather Goods

Official repository for **ZEMA**, an international-grade luxury accessories brand specializing in premium leather bags, luxury timepieces, genuine leather wallets, and handcrafted eyewear.

---

## 💎 Features & Structure

- **Luxury Editorial Experience**: Curated seasonal campaigns, refined visual hierarchy, and artisanal aesthetic.
- **Product Categories**:
  - **Bags**: Tote Bags, Shoulder Bags, Handbags, Crossbody Bags, Clutches.
  - **Watches**: Chronographs, dress watches, and precision timepieces.
  - **Wallets**: Bi-fold, cardholders, and slim leather wallets.
  - **Sunglasses**: Artisanal acetate and gold-rimmed UV400 eyewear.
- **Interactive E-Commerce**:
  - Cart, Wishlist, Quick View modal, and dynamic filtering.
  - WhatsApp Direct Ordering integration (`01032117373`).
  - Secure Admin Panel (`/admin/orders`) with PIN authentication.
- **Responsive Architecture**: Built with modern HTML5, Tailwind CSS tokens, and fluid responsive design for desktop, tablet, and mobile.

---

## 🚀 Running Locally

To run the local preview server:

```bash
python server.py
```

The application will be served at `http://localhost:5173`.
