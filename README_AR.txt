=====================================================
ZEMA Maison — متجر زيما المتكامل (الإصدار الفعلي الجاهز)
تاريخ التحديث: 2026-11-01
=====================================================

أبرز ما تم تجهيزه وتفعيله في الموقع بالكامل:
---------------------------------------------
1. نظام الشيك أوت واستقبال الطلبات المتكامل (Checkout System):
   - تفعيل خيار الدفع نقدًا عند الاستلام (Cash on Delivery - COD).
   - نموذج استلام بيانات العميل: الاسم، رقم الهاتف، المحافظة، المدينة/الحي، العنوان بالتفصيل، وأي ملاحظات.
   - حساب تكلفة الشحن تلقائيًا بناءً على المحافظة المختارة:
     * القاهرة والجيزة: 50 ج.م
     * القليوبية: 60 ج.م
     * الإسكندرية ومحافظات الدلتا والقناة: 65 ج.م
     * محافظات الصعيد: 75 إلى 85 ج.م
     * المحافظات الحدودية (البحر الأحمر، سيناء، مطروح، الوادي الجديد): 90 إلى 95 ج.م
   - شحن مجاني تلقائي لجميع الطلبات بقيمة 2,500 ج.م فأكثر.
   - توليد رقم طلب فريد لكل فاتورة تلقائيًا (مثال: #ZM-849201).
   - شاشة تأكيد وفاتورة فورية أنيقة للعميل (Order Confirmation & Receipt).
   - زر مباشر وفوري: "تأكيد وإرسال تفاصيل الطلب عبر واتساب" يفتح محادثة واتساب مع المتجر مباشرة برسالة كاملة منسقة تحتوي على تفاصيل المنتجات، الألوان، العنوان، والإجمالي المطلوب.
   - زر لطباعة الفاتورة يدعم تنسيق الطباعة الأنيق (Print Layout).

2. دعم اللغتين العربية والإنجليزية (Bilingual Support):
   - دعم التبديل السلس بين العربية والإنجليزية بنقرة زر واحدة (English / العربية) في الشريط العلوي والقائمة الجانبية.
   - التبديل الكامل للاتجاه بين (RTL) و (LTR) لجميع العناصر بدقة وتناسق بصري فاخر.
   - تعريب كامل للكتالوج وأسماء المنتجات، الألوان، الخامات، التفاصيل، وأقسام الموقع.

3. ميزة تنسيق وشراء المجموعات (Pair It With):
   - إمكانية إضافة الحقيبة مع القطع المتناسقة (محفظة أو تعليقة) مع خيارات الألوان وحساب الإجمالي لحظياً بنقرة واحدة.

4. السلة وقوائم الرغبات والمشاهدات الأخيرة:
   - سلة مشتريات جانبية ديناميكية وتفاعلية (Slide-over Cart Drawer).
   - حفظ المنتجات في قائمة الرغبات وسجل المشاهدات الأخيرة عبر التخزين المحلي (LocalStorage).

---------------------------------------------
كيفية تعديل رقم هاتف الواتساب وأسعار الشحن:
---------------------------------------------
افتح ملف catalog.js:
1. لتغيير رقم الواتساب:
   عدّل السطر الخاص بـ:
   whatsappNumber: "+201000000000"
   وضع رقم هاتفك المحمول بصيغة الكود الدولي (مثال: "+201012345678").

2. لتعديل أسعار الشحن أو المحافظات:
   ستجد مصفوفة EGYPT_GOVERNORATES حيث يمكنك تعديل سعر الشحن (fee) لأي محافظة بسهولة.

3. لتعديل حد الشحن المجاني:
   عدّل قيمة freeShippingThreshold (حالياً 2500 ج.م).

---------------------------------------------
طريقة التشغيل أو الرفع:
---------------------------------------------
- للتجربة والمعاينة: افتح ملف index.html مباشرة في أي متصفح.
- للنشر على الإنترنت: ارفع جميع ملفات المجلد إلى مستودع GitHub Pages أو أي استضافة مباشرة.
